# v0.1.0-alpha.15

发布日期：2026-10-27

## 重点

- WebView2 失败面板：错误原因、失败次数、重试按钮。
- 连续 3 次失败进入永久只读模式，并显示最近 50 条脉冲快照列表。
- 托盘图标改为 16/32/48 PNG 资源，按 DPI 选择，不再依赖 GDI+ 缩放。
- 任务 Tab 在 active_task 存在时显示 Marquee 进度条。
- 顶栏磁盘 / 时钟改为左侧布局，避免右侧不可见。
- 记忆页面在 `/remember`、`/extract` 写入后自动刷新。
- `disputed` 记忆使用 `bg-disputed #3A3520`。
- 急停按钮使用 `state-danger #F14C4C`。

## 已知边界

- 永久只读快照列表只展示脉冲，不含记忆/审计的完整只读表。
- 任务 Tab 只有 Marquee，没有步骤级明细。
- 脉冲路径不调用工具，`tool_calls` 为空是语义正确。
- 需要 Edge WebView2 Runtime。
