# v0.1.0-alpha.14

发布日期：2026-10-27

## 重点

- 最终外观收口：顶栏 / Tab 栏 / 底栏 / 状态卡分割线。
- 窗口启动位置与高度按工作区适配，避免高 DPI 下底栏被截断。
- Tab 内容增加顶部留白，修复首行被 Tab 栏遮挡。
- `disputed` 记忆使用配色书 `bg-disputed #3A3520`。
- 急停按钮改用语义色 `state-danger #F14C4C`，移除非规格 `DangerButtonBg`。
- 权限设置新增只读模式：禁止 WorkspaceWrite / Full 工具。
- 记忆设置新增检索条数（1–50），`/memory` 使用该值。
- 权限分组增加 face 审计 / 备用通道 / 主审计入口。
- 记忆分组增加 memory / semantic / episodic / disputed 文件入口。
- UI 状态注入：主窗口、当前 Tab、焦点、未完成意图、最近脉冲进入模型上下文。
