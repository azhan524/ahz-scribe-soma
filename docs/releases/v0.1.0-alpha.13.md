# v0.1.0-alpha.13

发布日期：2026-10-27

## 重点

- UI v1.5 观察窗：顶栏、左栏状态卡、顶部六 Tab、56px 底栏、托盘。
- .NET 10 渲染从 CefSharp 切换为 WebView2，脉冲 / 记忆 / 审计共用单实例。
- 脉冲详情 `PulseDetail` 落盘：`state_restore`、`thought`、`action`、`state_writeback`、`confidence`、`memories_injected`、`audit_id`。
- 审计备用通道：主审计不可写时写 `%LOCALAPPDATA%\Ahz\audit_fallback\audit_fallback.jsonl`，UI 显示 `[备用]`。
- 故障态测试入口：
  - `--audit-fallback-test`
  - `--sensor-stale-test`
  - `--schema-test`
- 托盘：状态色圆点、呼吸动画、暂停菜单、退出确认、三种气泡。
- BodySensor 心跳超过 90 秒自动重启。
- 设置：LLM / 身体 / 安全 / 权限 / 记忆 / 脉冲 / 主动性 / 人格分组；主动策略与脉冲周期可编辑。

## 已知边界

- 权限 / 记忆分组仍是说明卡，尚未全部可编辑。
- 脉冲路径没有工具调用，`tool_calls` 为空是语义正确，不是 UI 缺失。
- CefSharp 仅保留在 .NET Framework 4.8 兼容分支；.NET 10 使用 WebView2，需要 Edge WebView2 Runtime。
- 多显示器截图已覆盖虚拟桌面；相对点击需要先取 `desktop_screen_info`。
- 设置面板深度和最终 Codex 外观仍在打磨。

## 升级

```powershell
git fetch --tags
git checkout v0.1.0-alpha.13
dotnet build ahz-scribe-face/src/AhzScribe.Face.csproj
```

运行：

```powershell
ahz-scribe-face/src/bin/Debug/net10.0-windows/AhzScribe.Face.exe --ui
```

自检：

```powershell
AhzScribe.Face.exe --audit-fallback-test
AhzScribe.Face.exe --sensor-stale-test
AhzScribe.Face.exe --schema-test
```
