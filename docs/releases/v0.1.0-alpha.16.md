# v0.1.0-alpha.16

发布日期：2026-10-27

## 最终收口

这是 alpha 阶段的最终 UI 收口版本。

- 任务 Tab 增加步骤级明细：
  - [完成] 接收任务
  - [进行] 执行中
  - [等待] 写回结果
- 顶栏确认可见：空闲 / 前台 / 磁盘 / 时钟。
- WebView2 连续 3 次失败进入永久只读，快照覆盖脉冲、记忆、审计。
- 托盘 PNG 16/32/48，使用 white 模板 + 运行时 tint，呼吸动画恢复。
- UIStateBus 覆盖 WebView2 页面刷新。
- `Memories` 进入 `UiSnapshot`。
- 移除 UI 调试日志。
- 配色按 v1.1：
  - disputed `#3A3520`
  - 急停 `state-danger #F14C4C`
  - 急停纯白文字例外
